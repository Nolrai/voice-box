# Lore Directory Index

This folder contains narrative, worldbuilding, and in-universe technical documents for the Doll project. Canonical files are listed below; any temporary or superseded drafts should be removed or archived elsewhere.

## Canonical Files

- **DollHearing.md** — Technical and poetic summary of Doll phase-based hearing; merged from prior drafts.
- **FirstEars.md** — Narrative and technical account of the First Doll’s experiment to create hearing organs, exploring phase/interference-based perception and the origin of Doll auditory physiology.
- **PreDoll0_Speech.md** — The first Doll's speech and conceptual notes.
- **OnWaking.md** — Narrative prose, awakening sequence.
- **TheFirstConvergence.md** — Story fragment or world event.
## Drafts and brainstorming

- **drafts/gpt-musings-on-setting.md** — AI-generated setting notes and worldbuilding musings. This file contains raw brainstorming and speculative ideas; not part of the main narrative or technical canon. Move polished concepts into canonical docs as needed.

## Notes
- All files use `.md` for consistent Markdown rendering.
- If you add new stories, essays, or technical notes, please update this index.
- For technical documentation, see also `docs/tech/`.

## Related technical documents (in docs/tech)

- **LogTemplate.md** — A reusable development-log template for documenting experiments, parameters, observations, and next steps. Useful for keeping reproducible lab notes and linking iterations to the project's narrative arc.
- **PreDoll0_DevLog_001.md** — An example developer log / experiment entry for early PreDoll-0 iterations; shows how to record parameters, observations, and audio test outcomes.
- **VoiceEvolution_TechnicalAndPsychic.md** — Higher-level mapping of voice evolution stages: technical approach, aesthetic goals, and the in-universe psychic/ narrative significance for each phase.

## Related conceptual documents (in docs/concept)

- **DollHearing_Concepts.md** — Conceptual framework for Doll hearing, phase-based perception, and resonance; links to technical and lore docs.
- **VoiceEvolution_Concepts.md** — Conceptual mapping of voice evolution stages, technical and psychic meaning; links to related docs.
